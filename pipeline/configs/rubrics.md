# Scoring rubrics (0–5)

Use only extracted facts. Integer scores only.

## MCI_score
0 none · 1 background only · 2 weakly defined MCI in mixed cohort · 3 MCI group present, incomplete criteria · 4 standard MCI criteria + analysis · 5 MCI primary focus with clear staging

## AD_score
0 none · 1 intro only · 2 AD outcomes without biomarkers · 3 clinical AD/spectrum groups · 4 Aβ/tau/pTau/imaging define groups · 5 biomarker-confirmed AD staging focus

## Blood_score
0 no blood/plasma/serum · 1 mentioned unused · 2 routine labs only · 3 limited plasma/serum protein assays · 4 blood protein biomarkers main matrix · 5 primary blood-based discovery/validation

## Protein_score
0 none · 1 generic “biomarker” wording · 2 few named proteins, no proteomics · 3 targeted proteins/panels · 4 multiplex/proteomics with named results · 5 clear proteomic design + specific findings

## Quality_score
0 cannot judge · 1 anecdotal/unclear methods · 2 major gaps (n/groups/methods) · 3 adequate exploratory design · 4 clear groups, n, assay, stats · 5 high-quality with QC/replication

## Valid_score
0 none · 1 claimed without data · 2 weak internal split · 3 internal/technical confirmation · 4 independent cohort or orthogonal assay · 5 robust external validation + metrics
